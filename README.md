# לינק IN BIO · נופר גרגרוד · ממטק

דף "לינקטרי" אישי — מובייל‑פירסט, RTL מלא, עיצוב קוסמי עם אלמנטים מדעיים.

## 📂 מבנה התיקייה
```
index.html              ← הדף עצמו
assets/
  brain.png             ← לוגו המוח (שקוף)
  nofar.jpg             ← תמונת הפרופיל
  og.png                ← תמונת תצוגה מקדימה לשיתוף (1200×630)
  favicon-32.png        ← אייקון לשונית
  favicon-192.png
  apple-touch-icon.png  ← אייקון למסך הבית באייפון
```

## 🚀 העלאה ל‑GitHub Pages
1. צרו ריפו חדש (למשל `nofar-linktree`) והעלו אליו את **כל תוכן התיקייה הזו** (כך ש‑`index.html` יהיה בשורש הריפו).
2. בריפו: **Settings → Pages → Branch: `main` / root → Save**.
3. כתובת האתר תהיה: `https://<שם‑המשתמש>.github.io/<שם‑הריפו>/`

## ⚠️ חשוב — לפני העלאה
פתחו את `index.html` והחליפו את הכתובת `https://USER.github.io/REPO` בכתובת האמיתית של האתר,
בשלושת המקומות הבאים (כדי שתצוגת השיתוף ב‑וואטסאפ/פייסבוק תעבוד):
`og:url`, `og:image`, `twitter:image`, `canonical`.

## ✏️ עריכת קישורים
כל קישור הוא רכיב `<a class="card">` בתוך הקובץ — קל לערוך טקסט, כתובת או אייקון.
